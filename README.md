# DECKNSIDING — Website Project

[Visit the website](https://decknsiding.com/) · [Türkçe](README.tr.md)

## Overview

DECKNSIDING is a website presenting architectural wood products,
their applications, and resources for prospective customers and
professionals. Visitors can explore the collection and submit
project, quote, sample, or document inquiries.

This repository documents the website project for portfolio purposes.
It does not contain the website’s source code.

## My Role

**Website Design & Production Coordination — Duru Çalışkan**

I coordinated the website’s design and production process by
directing AI tools through instructions and feedback.

The website code was generated through AI tools. I did not write
or manually edit the code. My contribution was guiding the process
and communicating the desired website outcome.

## Project Scope

The published website includes:

- A wood product collection and application information.
- Resources for architects and builders.
- A contact form for project and product inquiries.
